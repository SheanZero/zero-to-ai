## 4 个语义段

### 1. Meta blockquote

```
> Auto-generated by `/szw-review` Phase 2; consumed by `/szw-write` Phase 1+2.
> Last updated: <date>; sample size: <X> articles, <Y> edit instances.
```

- `Last updated`: 最后一次 review commit 的日期
- `sample size`: 累计 article 贡献数 + 累计 edit instance 数
  - article 数：每次 review commit + 1（不去重 slug；同 slug 多次 review 算多份贡献，便于估计稳定度）
  - edit instances 数：每次 commit 累加 `n_added`（features 转出的 Recent Edits 行数）

复数处理：`article` vs `articles`；`edit instance` vs `edit instances`。

### 2. `## Stable Patterns（频次 ≥ 3，已合并）`

**当前不自动合并**（v3.0 deferred）。手工合并或未来 `/szw-cleanup` 触发：
- 把 `## Recent Edits` 中频次累计 ≥ `style_capture.min_pattern_frequency`（默认 3）的 pattern 提到对应子节
- 删除已合并的 Recent Edits 行

3 个子节：
- `### Vocabulary Substitutions`：表格，4 列（AI 倾向 / 作者偏好 / 频次 / 来源）
- `### Sentence / Rhythm`：bullet list（句式 / 节奏 / 段落偏好）
- `### Anti-Patterns（用户反复删除）`：bullet list（最高优先级；write Phase 1 必避）

### 3. `## Recent Edits（待合并的增量，每次 review 追加）`

主表，4 列：

| 列 | 内容 |
|---|---|
| 日期 | YYYY-MM-DD |
| Article | slug |
| Category | `vocab` / `sentence` / `rhythm` / `punctuation` / `anti-pattern` |
| Detail | 取决于 category（见下表） |

#### Detail 模板

| Category | Detail 模板 | 来源字段 |
|---|---|---|
| `vocab` | `AI 用 \`<ai>\` → 作者 \`<author>\` (freq=N)` | `vocabulary_substitutions[].{ai_pref, author_pref, frequency}` |
| `sentence` | `偏好 \`<pattern>\` (freq=N)` | `sentence_patterns[].{pattern, frequency}` |
| `rhythm` | 自由短语（直接来自字串） | `rhythm_paragraph[]` |
| `punctuation` | 自由短语 | `punctuation_mixing[]` |
| `anti-pattern` | `删除 \`<pattern>\`` | `anti_patterns[]` |

## /szw-write 如何使用

prepare-write.py 输出 `long_term_assets.style_profile`（路径或 null）。AI 在 Phase 1 起稿前必读此文件，重点：

1. **Anti-Patterns 区**：起稿时**绝对不用**这些词/句式
2. **Vocabulary Substitutions 表**：起稿时优先用作者偏好；避免 AI 倾向那侧
3. **Sentence / Rhythm 区**：起稿时尝试套用作者句式偏好
4. **Recent Edits 区**：可视为 "Stable 之外的最新偏好"；新出现 ≥ 2 次的也优先采纳

Phase 2 polish 时同样核对一遍。

## 配置项（szw-config.json）

```json
{
  "style_capture": {
    "enabled": true,                    // false → 跳过 Phase 2
    "diff_threshold_pct": 5,             // diff < 此值 → Phase 2 跳过（无显著编辑）
    "merge_after_n_reviews": 10,         // 累计 N 次后自动合并到 Stable Patterns（v3.0）
    "min_pattern_frequency": 3           // 合并阈值（v3.0）
  }
}
```

## 维护建议

- **不要手改 meta blockquote**：脚本会重写 `Last updated` + `sample size`
- **可以手改 Stable Patterns 表**：手工把 Recent Edits 里"看起来稳定"的 pattern 提上去；记得手动维护频次列
- **可以手删 Recent Edits 行**：若发现某条 pattern 是误判（一次性 edit 不代表偏好），手删即可
- **可以手改 Anti-Patterns**：直接增删 bullet
- **不要重命名 H2 标题**：脚本按精确文本（如 `## Recent Edits（待合并的增量，每次 review 追加）`）查找
- **退役整个文件**：mv 走或删除即可；下次 review 会重建
