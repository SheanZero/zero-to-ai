# 0003 - 不制造程序员职业焦虑

## Status

Accepted

## Date

<YYYY-MM-DD>

## Context

AI 编程话题容易被写成"程序员要被淘汰"的焦虑叙事。

这种写法有传播性，但容易牺牲准确性，也不符合本专栏的价值。

## Decision

不把"程序员被淘汰"作为默认叙事。

优先分析：

1. 哪些任务会被自动化
2. 哪些能力会升值
3. 哪些工作方式会变化
4. 程序员可以采取什么行动

如果某个判断无法转换成上述四类之一，重写 / 砍掉 / 换角度。

## Consequences

好处：
- 文章会更克制，但也更可信
- 与读者建立长期信任，而非一次性传播
- 与"行业分析 + 程序员建议"的定位一致

代价：
- 一些短期流量机会会被让出
- 标题写起来更难（不能用焦虑钩子）
