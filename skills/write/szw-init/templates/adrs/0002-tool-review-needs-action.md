# 0002 - 工具评测必须落到程序员行动建议

## Status

Accepted

## Date

<YYYY-MM-DD>

## Context

AI coding tools 的功能变化很快。单纯罗列功能，很快过时。

读者真正关心的是：这个工具会改变我的工作方式吗？我应该怎么用？

## Decision

所有工具评测必须回答 5 个问题：

1. 它改变了哪个开发环节？
2. 它适合哪类程序员？
3. 它不适合什么场景？
4. 程序员应该调整什么习惯？
5. 有哪些误用风险？

任何一个问题答不出来，文章不能发布。

## Consequences

好处：
- 文章不会是单纯产品说明，而会更像工作流分析
- 读者获得的是判断力，不是功能介绍
- 文章过时速度慢得多

代价：
- 写作前置思考更重
- 不适合追快讯节奏
- 如果工具刚发布信息不全，要主动延后
